# mahamud894.github.io

Personal portfolio of **Mahamud Hassan**, full-stack developer (Laravel, React, AI) from Khulna, Bangladesh.

Live at **https://mahamud894.github.io**

- Hand-written HTML, CSS and JavaScript, no framework and no build step
- Light and dark themes, keyboard friendly, respects reduced motion
- The hero runs a live accessibility check of the page itself, in the spirit of my open-source project [Curbcut](https://github.com/mahamud894/curbcut)

To run it locally, open `index.html` in a browser.
